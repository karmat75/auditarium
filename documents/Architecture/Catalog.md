# Katalog

Dokumente und Katalogversionen sind dauerhafte Fachkonzepte. Eine Katalogversion entsteht als `DRAFT`; ihre Dokumentelemente, Fragen, Geltungsbereiche und Gewichte werden in diesem editierbaren Zustand gepflegt. Erst eine valide Fassung kann den Zustand `READY` erreichen.

Sobald eine Version von einem Audit verwendet wird, bleibt ihre historische Bedeutung unverändert. Redaktionelle Weiterentwicklung erfolgt mit einem neuen oder kopierten `DRAFT`, nicht durch Änderung der verwendeten Fassung. Manuelle Pflege und Import führen, soweit verfügbar, in dasselbe Katalog-Domänenmodell.

Das versionierte externe Austauschformat ist in [CatalogImportFormat-v1](../ImportFormat/CatalogImportFormat-v1.md) beschrieben; diese Seite dupliziert dessen JSON-Schema nicht. Die historische Stabilität von Katalog und Audit-Snapshot folgt [ADR 0006](../ADR/0006-catalog-version-immutability-and-audit-materialization.md).
